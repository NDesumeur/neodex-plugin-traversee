# Traversée

Un poussin traverse routes et rivières, aussi loin que possible. Attention aux voitures, et ne tombe pas à l'eau !

Avance rangée par rangée : herbe, routes et rivières se suivent, sans fin. Les voitures écrasent, l'eau noie, et le bord de l'écran emporte. Chaque rangée gagnée compte un point.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Traversée → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
